# Issue tracker

Issues live in the repo's GitHub Issues: `ihmorol/carried`.

- Create and read issues with the `gh` CLI (`gh issue list`, `gh issue create`).
- PRs are a request surface, but they are not the triage queue: work items that
  need triage belong in Issues.
- Commit subjects reference the issue (`#123`) when applicable.

Configured for this repo on first setup (see `docs/agents/` for the other
agentic conventions).
