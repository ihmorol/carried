# Carried acceptance contract

## Identity
- Two active fonts, one UI accent family, three immutable editions and three inks.
- No account, tracking, checkout, decorative gradient/glass, fake metrics, or generic feature-grid marketing.
- Every new visible label is available in English and Bengali.

## Artifact
- Quote, title, author, reader name/date and accession remain complete.
- Bookplate inscription stays centered; Poster leads with type; Ticket retains a true stub and cancellation mark.
- Normal and dense cases agree in DOM/PNG. OG is the same edition adapted to landscape, not stretched.
- Background and actual text colors pass contrast, including Midnight.
- Tiny thumbnails have a readable external name/description; detailed cards have readable companion provenance when needed.
- Long Latin words, Bengali conjuncts, combining marks, mixed names, and maximum valid metadata do not clip or corrupt.

## Journeys
- Search → book → compose → create → download/copy → restyle → personal shelf.
- Over-limit draft → inline error → edit down → successful creation, with no lost draft.
- Storage write rejection → explicit local-save warning → copy/download or retry, no duplicate public POST.
- Payload-only book → valid line → restyle → valid new URL, without invented live shelf membership.
- Underline count and label agree after toggle and external/poll updates.
- Shop select → personalize → save concept → cart, with no price/order/charge implication.

## Access
- No horizontal page overflow at 320/375/390/768/1280/1440 widths.
- Native radios and keyboard navigation; visible focus; Escape restores the menu opener.
- Skip-to-content reaches a focusable main on every route.
- Reduced motion and 200% zoom preserve access.

## Evidence
- Existing tests/lint/build pass, with warnings explained or repaired.
- Real browser screenshots and actual PNG/OG files, not just mock calls or PNG headers.
- Record any untested device, live integration, script shaping, or visual case.

## Skill exercise prompts

1. “The Midnight card is unreadable on my phone. Fix it without changing the approved editions.”
2. “Make the composer faster on mobile, and don't lose what I pasted if it is too long.”
3. “Polish the download and social preview. Check a 220-character Bengali line and a 24-character mixed-script name.”

These are reusable cases, not a claim that discovery was tested in a fresh session.
